# NC — Namit Chougale | Personal Portfolio (v3)

A responsive, single-page portfolio for Namit Chougale, a first-year Electronics and Communication Engineering student interested in learning cybersecurity, electronics and programming.

## What's new in v3
- Custom **NC** monogram and prominent **Namit Chougale** hero typography (Space Grotesk + Instrument Serif).
- **Animated coding lab** in place of the waveform: rotating loop illustration, typewriter examples of Python, C and HTML, language controls, play/pause and sample outputs. This is a visual animation, **not** a code execution sandbox.
- **Cyber Toolkit** has an independent **teal / ice-blue** project identity.
- **Redstone Logic Lab** has an independent **red / copper** project identity.
- Headings animate word-by-word as they scroll into view, with staggered skills and soft scroll-linked parallax.
- Switchable **dark/light themes** with saved settings and accessibility-minded reduced-motion behaviour.
- No build tooling or paid APIs required. Works on desktop, tablet and mobile.

## Run locally
Extract the ZIP and open `index.html` in Chrome, Edge or Firefox. The SHA-256 preview requires a secure browser context, so to test hashing use `http://localhost` or an HTTPS deployment if opening the file directly doesn't expose `crypto.subtle`.

## Deploy on GitHub Pages
1. Create a public GitHub repository such as `nc-portfolio`, or use an existing portfolio repository.
2. Upload **all** contents of this extracted folder to the repository root: `index.html`, `styles.css`, `script.js` and `assets/favicon.svg`.
3. Open your repository **Settings → Pages → Build and deployment**.
4. Under **Source**, select **Deploy from a branch**, and select `main` and `/ (root)`.
5. Save and open the GitHub Pages URL when deployment completes.

## Customize
- **Content / headline / links:** `index.html`
- **Appearance / typography / colours / motion:** `styles.css`
- **Theme persistence / coding loop / portfolio demos / scroll effects:** `script.js`

Google Fonts are used for Space Grotesk, DM Mono and Instrument Serif, with local fallbacks. No analytics, tracking or account login is included.
